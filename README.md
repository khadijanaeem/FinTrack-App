FinTrack is a comprehensive MERN stack web application designed to help users efficiently manage their personal finances. With an intuitive dashboard, powerful analytics, and robust budgeting tools, FinTrack makes financial tracking simple, secure, and accessible from any device.

💰 Stop wondering where your money goes - start tracking it with FinTrack!

🚀 Key Features 💳 Financial Management Income & Expense Tracking - Add, edit, and categorize transactions

Smart Budgeting - Set monthly budgets with visual progress tracking

Financial Dashboard - Interactive charts and spending analytics

PDF Reports - Generate and download monthly financial summaries

🔐 Security & User Experience JWT Authentication - Secure login/signup with encrypted passwords

Responsive Design - Seamless experience across all devices

User Profiles - Customizable settings and preferences

Admin Panel - User management and analytics (for administrators)

📈 Advanced Analytics Spending Trends - Visualize expenses with Chart.js graphs

Category Analysis - Understand spending patterns by category

Budget Alerts - Email notifications for budget limits and bill reminders

Search & Filter - Find transactions by date, category, or keyword

🌐 Additional Features Contact System - Integrated contact form with Google Maps

Social Links - Connect with developer profiles

Email Notifications - Automated reminders and reports

RESTful API - Clean, well-documented backend API

🛠 Tech Stack Frontend:

⚛️ React.js with Hooks

🎨 Redux Toolkit for State Management

💅 Tailwind CSS for Styling

📊 Chart.js for Data Visualization

📄 jsPDF for Report Generation

Backend:

🟢 Node.js & Express.js

🗄️ MongoDB with Mongoose ODM

🔑 JWT & bcrypt for Authentication

📧 Nodemailer for Email Service

🛡️ Helmet & CORS for Security

Deployment:

▲ Vercel (Frontend)

⚡ Render (Backend)

☁️ MongoDB Atlas (Database)
